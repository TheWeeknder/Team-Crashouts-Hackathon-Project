# AI Prompt Tracker

This project records every use of AI tools, for transparency with the hackathon judges. Each team member keeps their own log in [`prompts/`](prompts/), so entries from different branches no longer conflict or get duplicate numbers.

## Where to log

Add each entry to **your own file**, using the template at the top of that file:

| Person | Side | Log |
| --- | --- | --- |
| Justin | Backend | [prompts/Justin.md](prompts/Justin.md) |
| Cody | Backend | [prompts/Cody.md](prompts/Cody.md) |
| Robin | Frontend | [prompts/Robin.md](prompts/Robin.md) |
| JP | Frontend | [prompts/JP.md](prompts/JP.md) |

Each entry records the date, the tool and model, the exact prompt, what the AI produced or changed, and a human review of what the team kept, edited or rejected.
