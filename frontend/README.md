# Frontend

The React + TypeScript + Vite client for the Adaptive Study Planner.

See the [root README](../README.md) for setup, the API overview and how the app works, and [docs/ROADMAP.md](../docs/ROADMAP.md) for the team plan and current status.

Quick start (the backend must be running on port 8000):

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production build in dist/
npm run lint
```
