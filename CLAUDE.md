## AI usage logging (required)

All AI usage on this project must be documented for the hackathon. Each team member has their own log in [`prompts/`](prompts/):

| Person | Log |
| --- | --- |
| Justin | [prompts/Justin.md](prompts/Justin.md) |
| Cody | [prompts/Cody.md](prompts/Cody.md) |
| Robin | [prompts/Robin.md](prompts/Robin.md) |
| JP | [prompts/JP.md](prompts/JP.md) |

For every prompt you receive in this repo, append a numbered entry to the **Log** section of the sender's own file before you finish the turn. Number it one higher than the last entry in that file. Use the entry template at the top of that file and include:

- the date
- the tool and model
- the team member who sent the prompt
- the exact prompt text
- a short summary of the files created or changed

If you don't know who sent the prompt, check the git user name and the branch name. If they don't make it clear, ask.

Never write entries into another person's file. Don't add new entries to [Prompts.md](Prompts.md): it is the index for judges, with a frozen table of the old shared log (entries 1 to 44).

Leave **Human review** as `_TBD_` for the team to fill in.
