# CLAUDE.md

## AI usage logging (required)

All AI usage on this project must be documented in [Prompts.md](Prompts.md) for the hackathon.

For every prompt you receive in this repo, append a numbered entry to the **Log** section of `Prompts.md` before you finish the turn. Use the entry template in that file and include:

- the date
- the tool and model
- the team member who sent the prompt, if known
- the exact prompt text
- a short summary of the files created or changed

Leave **Human review** as `_TBD_` for the team to fill in.
